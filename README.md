# NAREZ 3.0 — Website

A responsive static landing page and draft legal pages for the NAREZ project.

## Files
- `index.html` — landing page
- `terms.html` — Terms of Service draft
- `privacy.html` — Privacy Policy draft
- `assets/style.css` — styling and animations
- `assets/icon.svg` — favicon

## Publish with GitHub Pages
1. Extract the ZIP archive.
2. Open the `linuxTEMA0110/narez-3-0` repository.
3. Choose **Add file → Upload files**.
4. Upload the contents of the extracted folder (the HTML files, `README.md`, and the `assets` folder). Do not upload only the ZIP.
5. Commit the upload to the `main` branch.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
8. Wait for GitHub Pages to publish the site.

Expected URLs:
- `https://linuxtema0110.github.io/narez-3-0/`
- `https://linuxtema0110.github.io/narez-3-0/terms.html`
- `https://linuxtema0110.github.io/narez-3-0/privacy.html`

## Important before public submission
The Terms and Privacy pages are drafts. Confirm that the actual app's data collection, token storage, retention, deletion, hosting and support arrangements match the text. Replace or supplement the draft with accurate operator/contact details and obtain legal review where appropriate. TikTok may review the live pages and the app itself; publishing these pages does not guarantee app approval or API access.
